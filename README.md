Portfólio profissional desenvolvido para apresentar minha trajetória, conhecimentos técnicos e projetos práticos na área de Análise de Dados, Business Intelligence e tecnologia.

## Objetivo do projeto

Criar um espaço profissional para reunir meus projetos, apresentar minhas competências técnicas e facilitar o acesso de recrutadores e profissionais de tecnologia ao meu trabalho.

O portfólio também representa uma oportunidade de aplicar conhecimentos de desenvolvimento web, organização de código e publicação de aplicações estáticas.

## Tecnologias utilizadas

- **HTML5:** estruturação semântica do conteúdo.
- **CSS3:** estilização, layout responsivo, animações e efeitos visuais.
- **JavaScript:** interatividade e funcionamento do menu de navegação.
- **Git:** controle de versionamento.
- **GitHub:** hospedagem e gerenciamento do repositório.
- **GitHub Pages:** publicação do site.

## Funcionalidades

- Layout responsivo para computadores, tablets e smartphones.
- Menu de navegação adaptado para dispositivos móveis.
- Apresentação profissional com foto de perfil.
- Seção dedicada à trajetória e aos objetivos profissionais.
- Projetos em destaque com imagens, descrições e tecnologias utilizadas.
- Cards de projetos inteiramente clicáveis, direcionando aos respectivos repositórios.
- Efeitos de hover nos cards e nas imagens.
- Seções de tecnologias, formação, certificações e idiomas.

## Projetos em destaque

O portfólio apresenta cinco projetos desenvolvidos durante meus estudos e minha transição de carreira para a área de dados.

### 1. Perfect Store Analysis

Análise do desempenho operacional de 50 filiais de uma rede de restaurantes, utilizando dados de 12 meses para avaliar indicadores, identificar oportunidades de melhoria e desenvolver visualizações gerenciais.

**Tecnologias:** Python, Pandas e Power BI.

[Ver repositório](https://github.com/DanielDevCC26/perfect-store-analysis)

### 2. SaaS Churn Analysis

Projeto de Machine Learning voltado à previsão de cancelamento de clientes em um serviço SaaS.

Inclui análise exploratória, preparação dos dados e comparação de modelos de classificação, como Regressão Logística, Random Forest e XGBoost.

**Tecnologias:** Python, Pandas, Scikit-learn e XGBoost.

[Ver repositório](https://github.com/DanielDevCC26/saas-churn-analysis)

### 3. EDA Tech Store

Análise exploratória de dados comerciais de uma loja de tecnologia, investigando indicadores de vendas e padrões de desempenho.

**Tecnologias:** Python, Pandas e Matplotlib.

[Ver repositório](https://github.com/DanielDevCC26/eda-tech-store)

### 4. Delivery Data Analysis

Análise exploratória de dados de pedidos de delivery, com foco em faturamento, comportamento das vendas e indicadores operacionais.

**Tecnologias:** Python, Pandas e visualização de dados.

[Ver repositório](https://github.com/DanielDevCC26/delivery-data-analysis)

### 5. Customer Data Cleaning

Projeto de limpeza e preparação de dados de clientes, abordando identificação de inconsistências, padronização de informações e melhoria da qualidade dos dados.

**Tecnologias:** Python e Pandas.

[Ver repositório](https://github.com/DanielDevCC26/customer-data-cleaning)

## Executando o projeto localmente

Como o site utiliza HTML, CSS e JavaScript, não é necessário instalar dependências.

### 1. Clone o repositório

```bash
git clone https://github.com/DanielDevCC26/DanielDevCC26.github.io.git
```

### 2. Acesse a pasta

```bash
cd DanielDevCC26.github.io
```

### 3. Abra o projeto

Abra a pasta no Visual Studio Code e execute o arquivo `index.html` no navegador.

Também é possível utilizar a extensão Live Server para visualizar as alterações durante o desenvolvimento.
